# HistoryIn3D
Diploma Thesis - University of Patras

ABSTRACT

The object of this thesis is the design and development of the app HistoryIn3D, an app for 
Android devices,  μια εφαρμογή για Android συσκευές, that allows users to navigate the site 
of the roman stadium of Patras while seeing a 3D recreation and reconstruction of it in their 
mobile device. The 3D model, which is a recreation of the stadium in the roman years, is 
placed by the user in the site and fits on the ruins in a way that allows the user to walk inside 
it, and learn more information about it. Moreover, by recognizing gestures, the user can 
manipulate the visibility of certain levels of the stadium. 
The tools used for the implementation of the application were Blender for the creation of 
the model and Unity for the app itself. In particular, the XRFramework plugin of Unity was 
used for the placement of the model and the navigation of the user inside it, and the 
MediaPipe plugin of Unity was used for to recognize gestures
